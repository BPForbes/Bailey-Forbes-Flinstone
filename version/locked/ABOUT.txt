Version release notes use *.ver files (MAJOR_VERSION, STANDARD_VERSION,
RELEASE_VERSION or MINOR_VERSION / VERSION_PATCH, and DESCRIPTION).

version/entries/  — author and edit .ver release notes here before finalize.
version/locked/   — published snapshot: replaced by copying entries → locked.

Finalize (copy all of entries over locked), then regenerate the shell header:

  ./scripts/finalize_version_locked.sh   # or: make finalize-version-locked
  make                                   # or: ./scripts/gen_version_def.sh

userland/shell/version_def.h is generated from the highest A.B.C among
version/locked/*.ver only. Do not edit the header by hand.

The repository currently ships e.g. 001_2_2_4_baseline.ver. Add new releases as
additional *.ver files here; include the semver in the basename (often with a
serial prefix). Ordering uses MAJOR/STANDARD/RELEASE inside the file, not the
filename prefix.
