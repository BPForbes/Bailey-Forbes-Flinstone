MitM + RS lab

Drives netlab in the shell — no typing needed. Everything below runs against fabricated hosts and a mock victim; nothing here touches a real network or another visitor's session. netlab help in the terminal lists every verb.

Network segment

Picks which fabricated network the recon and MitM buttons below act on.

Pod (private group)

A pod is a private, named group for one MitM + RS exercise. Each member keeps their own identity; the creator is the host, and the next member becomes host if they leave.

Reverse shell (simulated)

Opens a simulated reverse shell to a mock victim. While open, netlab <cmd> in the terminal runs as that victim (e.g. netlab whoami returns the victim's name); your own whoami is unchanged. Opening it isolates the lab from the real network, the same as Start demo below; closing it restores the network.
